# Arcgentic v2.0.0 Release Checklist

## Release positioning

Arcgentic v2.0.0 is the V2 orchestration release.

- Codex V2 is complete and verified in a real project workflow.
- Codex verified path includes automatic Orchestrator setup, fixed role
  thread/agent creation or reuse, role prompt dispatch, active role return, and
  next-role routing without manual thread creation.
- Claude Code V2 is complete as an experimental hook-backed broker, but has not
  yet been verified in a real Claude Code session.
- The npm package is a zero-dependency plugin asset bundle and installer helper,
  not a replacement for the Python CLI.

## Local release gates

Run from the repository root:

```bash
git status --short
git diff --check README.md README.zh-CN.md plugin.json .claude-plugin/plugin.json .codex-plugin/plugin.json openclaw.plugin.json .claude-plugin/marketplace.json toolkit/pyproject.toml package.json
python3 -m pytest toolkit/tests
python3 -m mypy --strict toolkit/src toolkit/tests
python3 -m ruff check toolkit/src toolkit/tests
node bin/arcgentic.js --help
npm pack --dry-run
python3 -m build toolkit
```

Run the existing shell tests:

```bash
for f in $(find scripts tests -name '*.test.sh' -o -name '*.sh' | sort); do
  case "$f" in
    scripts/*.test.sh|tests/*.test.sh) bash "$f" ;;
  esac
done
```

## External publishing steps

Do these only after local gates pass and the release commit is pushed.

1. Create and push the tag:

   ```bash
   git tag -a v2.0.0 -m "Arcgentic v2.0.0"
   git push origin main v2.0.0
   ```

2. Create the GitHub release for `v2.0.0`.

3. PyPI publishing:

   - The existing `Publish Python toolkit` workflow publishes from
     `toolkit/dist/`.
   - Requires the GitHub `pypi` environment and trusted publishing to be
     configured for `arcgentic`.

4. npm publishing:

   - The `Publish npm bundle` workflow publishes the root package.
   - Requires the GitHub `npm` environment and npm trusted publishing to be
     configured for package `arcgentic`.
   - The package name `arcgentic` currently returned npm registry `E404` during
     local availability check, so it is a viable first choice.

5. Claude Code plugin marketplace:

   - `.claude-plugin/marketplace.json` and `.claude-plugin/plugin.json` are
     versioned to `2.0.0`.
   - Publish through the marketplace process after GitHub release is visible.

6. Codex local/plugin surface:

   - `.codex-plugin/plugin.json` is versioned to `2.0.0`.
   - The npm bundle can install the local Codex plugin with:

     ```bash
     npm install -g arcgentic
     arcgentic install-codex-local
     ```

## Release notes draft

Arcgentic v2.0.0 turns AI coding from ad-hoc prompting into an orchestrated,
gated engineering workflow.

Highlights:

- Codex V2 verified in a real project workflow.
- Current project conversation becomes `Orchestrator`.
- Orchestrator automatically creates or reuses fixed role threads/agents.
- Role prompts are dispatched automatically.
- Planner, Developer, optional Test, and Auditor actively return to
  Orchestrator.
- Single-session multi-agent mode and multi-session multi-thread mode are both
  represented in the V2 workflow.
- Claude Code V2 is included as an experimental hook-backed broker.
- README and README.zh-CN now explain the Moirai-derived origin, target users,
  automation behavior, and overkill boundary.
- npm package added as a release bundle and Codex local install helper.

Known limitation:

- Claude Code V2 has not yet been verified in a real Claude Code session.
